github apival kapcsolatos kérdés, hogy mit érdemes id-nak használni.
ezen felül egyébként a fő azonosító kulcs az adatbázisban a "<gitprovider_id>:<external_id>" lett, tehát például "github:83221" vagy "gitlab:123123" formátumban. Ez azért jó, mert ha két ugyanolyan id-t kapunk két különböző gitprovider apijától, akkor nem vesznek össze
